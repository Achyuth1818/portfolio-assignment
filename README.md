# Portfolio Assignment

This project is a basic portfolio built using **React** and **Tailwind CSS**. It showcases my hobbies and professional summary in a clean and responsive design.

## Features

- Responsive layout
- Clean and modern design

## Getting Started

To clone and run this project, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Clone the Repository

```bash
git clone https://github.com/Achyuth1818/portfolio-assignment.git
cd portfolio-assignment/frontend
npm install
npm i react-router-dom
npm run dev
